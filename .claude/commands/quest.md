# 🎮 Quest Initiation Protocol

Welcome, brave Code Architect! You're about to embark on a new development quest in the CodeCraft realm.

## Quest Setup

When starting a quest, I'll need to know:
1. **Quest Type**: What are you building? (API, Frontend, Full-Stack, Tool, Library)
2. **Difficulty**: Your experience level (Beginner, Intermediate, Expert, Legendary)
3. **Time Frame**: Sprint duration (Quick Quest: 1hr, Standard: 1 day, Epic: 1 week+)
4. **Technology Preference**: Your preferred stack or let me suggest

## Quest Structure

Every quest includes:
- **Main Objective**: The primary goal to achieve
- **Side Missions**: Optional challenges for bonus XP
- **Boss Battles**: Major technical challenges to overcome
- **Loot Rewards**: Code patterns, tools, and knowledge gained

## Usage Examples

```
/quest api
Start an API development quest with auto-detected difficulty

/quest frontend beginner
Begin a beginner-friendly frontend quest

/quest fullstack epic
Embark on an epic full-stack application journey
```

## Quest Workflow

1. **Quest Briefing**: I'll present the quest objectives and rewards
2. **Party Assembly**: Choose which AI agents to bring (Architect, Validator, Optimizer)
3. **First Decision**: Make your initial architectural choice
4. **Parallel Paths**: Option to run multiple quest branches simultaneously
5. **Progress Tracking**: Real-time XP and achievement updates
6. **Victory Conditions**: Clear goals for quest completion

## Special Quest Types

### 🏃 Speed Run Quest
Complete a project as fast as possible with time bonuses

### 🏆 Perfect Score Quest
Focus on code quality, achieving 100% test coverage and A+ ratings

### 🤝 Guild Quest
Collaborative quest designed for team development

### 🔮 Mystery Quest
I choose the project based on your skills and interests

### 🔄 Refactor Quest
Transform legacy code into modern architecture

## Quest Rewards

- **XP**: 100-1000 based on complexity
- **Achievements**: Unique badges for special accomplishments
- **Unlocks**: New widgets, agents, and capabilities
- **Knowledge**: Patterns and best practices
- **Code**: Real, production-ready implementation

## Active Effects During Quest

- **Focus Mode**: Concentrated assistance on quest objectives
- **Auto-Save**: Git commits at each milestone
- **Hint System**: Contextual tips when stuck
- **Parallel Execution**: Run multiple quest branches
- **Boss Assistance**: Extra help during difficult challenges

## Ready to Begin?

Simply type `/quest` followed by your desired quest type, or just `/quest` to start the interactive quest selector!
