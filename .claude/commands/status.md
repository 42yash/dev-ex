# 📊 CodeCraft Status Dashboard

View your complete development journey statistics, achievements, and progress!

## Status Categories

### 🎮 Player Profile
```
/status profile
```
Shows:
- Username and Title
- Current Level and XP
- Class and Specialization
- Play Time and Join Date
- Current Guild

### 📈 Game Statistics
```
/status stats
```
Displays:
- Total Quests Completed
- Lines of Code Generated
- Bugs Fixed / Created Ratio
- Test Coverage Average
- Code Quality Rating
- Decision Accuracy

### 🏆 Achievements
```
/status achievements
```
Lists:
- Unlocked Achievements
- Progress on Current Achievements
- Rare Achievements Earned
- Achievement Points Total
- Next Achievement Hints

### 💰 Resources
```
/status resources
```
Shows:
- Code Coins Balance
- Architecture Gems
- Knowledge Points
- Energy/Stamina
- Boost Items
- Crafting Materials

### 🗺️ Quest Progress
```
/status quests
```
Tracks:
- Active Quests
- Completed Quests
- Quest Success Rate
- Current Quest Phase
- Parallel Quest Status
- Upcoming Quests

### 🤖 Agent Relationships
```
/status agents
```
Shows:
- Agent Friendship Levels
- Agent Abilities Unlocked
- Agent Quest History
- Favorite Agent
- Agent Synergies

### 🔄 Bootstrap Progress
```
/status bootstrap
```
Special meta-tracking:
- Self-Build Percentage
- Components Created
- Widgets Built
- Evolution Stage
- Singularity Distance
