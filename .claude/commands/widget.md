## Widget Interaction Format

When summoned, widgets appear as ASCII art with interactive elements:

```
┌─────────────────────────────────┐
│     [Widget Title]              │
├─────────────────────────────────┤
│                                 │
│    [Visual Representation]      │
│                                 │
│    [Interactive Options]        │
│                                 │
│    Your Choice: _              │
└─────────────────────────────────┘
```

## Widget Mechanics

### Input Methods
- **Letter Selection**: Choose options with [A], [B], [C]
- **Numeric Values**: Enter numbers for configurations
- **Drag Indicators**: Use arrows to show connections
- **Pattern Entry**: Type patterns or expressions

### Scoring System
- **Speed Bonus**: Complete widgets quickly for extra XP
- **Accuracy Points**: Optimal solutions earn more rewards
- **Combo Multiplier**: Chain correct decisions
- **Perfect Clear**: All requirements met perfectly

### Real-Time Effects
Every widget interaction:
1. Generates actual code
2. Updates project structure
3. Awards XP and achievements
4. Affects future options
5. Saves to Git branch
